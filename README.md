Bukti hasil eksekusi ada di folder screenshots/.

## Cara menjalankan

1. python -m venv venv
2. source venv/bin/activate
3. pip install -r requirements.txt
4. python hello.py

## Catatan

Kode mengikuti topik artikel Santrikoding, sedangkan data dan contohnya disesuaikan sendiri. Pengerjaan dilakukan di WSL2 Arch Linux dengan virtual environment bernama venv. File requirements.txt tidak berisi dependensi karena hanya memakai pustaka standar.
